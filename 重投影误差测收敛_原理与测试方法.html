重投影误差测 EKF 收敛：原理与测试方法

一句话：重投影误差 = 三维状态误差在图像上的可观测投影。没有真值测不到状态误差，但每帧都能测到「预测投影点 vs 实际检测点」的像素差；误差落到噪声底 = 已收敛，误差大/振荡 = 未收敛或模型错。

① 原理：状态 → 投影 → 与检测对比

② 收敛曲线示意：误差随时间的典型形态

示意：曲线为说明性数据，非实测记录。

③ 怎么测：每帧闭环 + 聚合指标

每帧流程（离线 rosbag 回放 / 在线）
  1. 取检测：装甲四角/中心像素点（带时间戳）
  2. 取状态：EKF 输出的世界系 buff 中心、yaw/pitch、ω
  3. 模型预测：θᵢ = θ + i·72°，装甲点 = 中心 + 半径 r → 三维点 P_w
  4. 投影：û = K·[R|t]·P_w（内参 + 外参/里程计）
  5. 算误差：每点 e = ‖p̂ − p‖，每帧取平均与最大
  6. 聚合指标并画曲线
四个指标
  • 收敛时间：从首帧到误差持续 < 判敛线（连续 N 帧）的帧数
  • 稳态 RMS：收敛后误差均方根，与检测噪声 σ 对比
  • NIS 一致性：标准化新息按 χ²(2) 检验，均值应 ≈ 2
  • 残差自相关：收敛后应为白噪声；若随旋转频率振荡 → 模型错

④ 测试场景与判据

场景 做法 看什么 / 怎么用
静态测噪底机关不动误差应落 1~3px → 得 σ，定判敛阈值
初始化偏差给错初值 / 中途重初始化收敛帧数、有无过冲振荡 → 判初值鲁棒性
遮挡恢复遮挡 0.5~2s 再露出尖峰后重新收敛帧数 → 判预测外推能力
变速慢 / 中 / 快转速高速下误差抬升 = 预测滞后 → 调过程噪声 Q / ω 模型
真值对照（可选）编码器 / 已知角度状态误差 vs 重投影误差是否同步 → 验证代理有效性
调参判据（对应你正在调 R / Q）：稳态 RMS ≤ 2~3×σ（通常 <5px）→ 收敛良好；NIS 均值 ≫ 2 → Q 太小（过度自信）或 R 偏小；NIS 均值 ≪ 2 → Q 太大（迟钝）。
注意误差耦合：若相机位姿 R,t 来自同一装甲的 PnP，重投影误差会混入 PnP 误差，不是纯滤波收敛；改用里程计/陀螺位姿，或把两条来源分开记录对比。
